职业技能_武士
新浪游戏 2005-03-31 09:56
◆ 职业技能 ◆ 技能树

武 士 法 师 道术士

基本剑术
基本剑术是武士的入门剑术。剑术招式是很久以前帝国的士兵们从战场上领悟到的。基本剑术学习起来非常容易，没有什么花哨的招式，属于剑术中的基本功。随着练习程度的深入，对增加攻击命中率很有帮助。
- 1等级 : 7级可以开始修炼
- 2等级 : 9级可以开始修炼
- 3等级 : 11级可以开始修炼
攻杀剑术
攻杀剑术也属于入门剑术，其目标是修炼爆发力，修炼时要求精神高度集中。修炼攻杀剑术到了一定境界，就能在瞬间爆发出强大的攻击力，给敌人强烈打击。
- 1等级 : 14级可以开始修炼
- 2等级 : 16级可以开始修炼
- 3等级 : 18级可以开始修炼
刺杀剑术
刺杀剑术是必须有一定武功基础才能够修炼的中级剑术，刺杀剑术讲求“快”、“准”、“狠”，经过刻苦修炼后，可以从出其不意的部位出手攻击敌人，达到最高境界时，甚至可以杀死数丈之外的敌人。
- 1等级 : 19级开始修炼
- 2等级 : 21级开始修炼
- 3等级 : 23级开始修炼
半月弯刀
修炼半月弯刀的基础是“内力”，使用时会发出银色的月魄，与之前所学的武功不同，半月弯刀的攻击范围要广的多，可以同时攻击附近的数个敌人。使用半月弯刀需要消耗内力。
- 1等级 : 24级开始修炼
- 2等级 : 26级开始修炼
- 3等级 : 28级开始修炼
野蛮冲撞
野蛮冲撞是武士勇气与力量的体现，可以帮助武士们从敌群中脱险而出，也可以起到搅乱敌阵的效果。一定要注意的是，修炼不足的情况下使用野蛮冲撞，反而会惹祸上身，而且，对等级比自己高的敌人无效。
- 1等级 : 27级开始可以修炼
- 2等级 : 29级开始可以修炼
- 3等级 : 31级开始可以修炼
烈火剑法
烈火剑法是使用内功的更高境界，将胸中的怒火注入手中的武器之中，唤起刀剑的杀气，可以造成惊人的破坏力。由于消耗过大，这种武功不能连续使用，另外修炼不足的情况下，聚气成功的可能性会降低。
- 1等级 : 32级开始可以修炼
- 2等级 : 34级开始可以修炼
- 3等级 : 36级开始可以修炼
翔空剑法
翔空剑术是名动武林的著名剑术之一。使用者盘持剑腾空，然后全力劈下，气势磅礴，威力无双，可以攻击身边的多个敌人。由于消耗过大，这种武功不能连续使用。
- 1等级 : 35级开始可以修炼
- 2等级 : 37级开始可以修炼
- 3等级 : 39级开始可以修炼
莲月剑法
莲月剑法是江湖中盛传的最高剑法之一。使用时会发出莲花一样灿烂的剑光，令对方根本没有反击的机会，给敌人造成致命的打击。若没有坚实的内功和体力，是无法使用此剑术的。由于消耗过大，这种武功不能连续使用。
- 1等级 : 38级开始可以修炼
- 2等级 : 40级开始可以修炼
- 3等级 : 42级开始可以修炼
十方斩
十方斩——以闪电般的速度向四面八方发出强烈的剑气。这种威力无穷的武功和“半月弯刀”是同一位遁世高人所创，因为发招时需要消耗巨大的内力，普通人很难练成，因而几近失传。然而玛法的勇士们经过不懈的努力，终于令它得以重现。虽说真正的武功高手不会轻易被诱入包围，但当他们不可避免地身陷敌阵，十方斩就会在此时发挥出无与伦比的威力。
- 1等级: 40级开始修炼.
- 2等级: 43级开始修炼.
- 3等级: 46级开始修炼.
乾坤大挪移
乾坤大挪移——以极快的身法在瞬间调换自己和敌人的位置，占据有利地形.施展乾坤大挪移需要非常敏捷的身法以及深厚的功力.只有在对方实力不如自己时生效，而且初学者的成功率往往不高.另外，乾坤大挪移是一位
远古英雄为了对抗魔族而发明的，所以用在人类身上效果并不明显.
- 1等级: 42级开始修炼.
- 2等级: 45级开始修炼.
- 3等级: 48级开始修炼.
铁布衫
铁布衫——金铁布衫本是武林中“护心”流派的武功，他们认为要想取胜，就必须先令自己处于不败之地.铁布衫需要牺牲施展者的攻击力来加强防御和魔御，多用于攻城战或打击攻高血少的敌人.不要以为这是弱者才会修习的武功，事实上如果攻击力低的人贸然修炼金钟罩，就会在一段时间内武功尽失.
- 1等级: 44级开始修炼.
- 2等级: 47级开始修炼.
- 3等级: 50级开始修炼.
斗转星移
斗转星移——据说发明斗转星移的高手曾修炼过道家功夫，但现在却只有武士能够使用得得心应手。斗转星移可以将远处的敌人瞬间拉到自己身边，然后施以打击。最适用于对付远距离攻击的怪物，但对人类收效甚微。
- 1等级: 46级开始修炼.
- 2等级: 49级开始修炼.
- 3等级: 52级开始修炼.
破血狂杀
破血狂杀——这本是狂战士的独门武功，以牺牲体力和防御力为代价提高自身攻击力.曾经有很多武士为了修炼破血狂杀走火入魔，但因为它能带来可怕的攻击力，试图掌握它的人从来就没有减少过.尽管如此，因为它消耗的体力过大，使用时一定要慎重.
- 1等级: 48级开始修炼.
- 2等级: 51级开始修炼.
- 3等级: 54级开始修炼.
